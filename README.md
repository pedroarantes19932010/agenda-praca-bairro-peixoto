# Agenda da Praça do Bairro Peixoto

Protótipo de uma agenda comunitária para reunir e divulgar atividades realizadas na Praça do Bairro Peixoto, em Copacabana, Rio de Janeiro.

**Demonstração:** [abrir o site publicado](https://agenda-praca-bairro-peixoto.determinedborage1.chatgpt.site)

## Contexto

A proposta parte de uma necessidade local: moradores encontram atividades de esporte, cultura e convivência na praça, mas não têm um lugar único para consultar a programação. O projeto explora como uma página simples pode organizar essas informações e facilitar a comunicação com a comunidade.

Este é um projeto acadêmico de extensão e um protótipo inicial. A página não representa oficialmente a praça nem uma associação comunitária.

## O que a página apresenta

- Atividades comunitárias organizadas por categoria, com imagens ilustrativas.
- Agenda demonstrativa com horários entre 09h e 17h.
- Formulário de proposta de atividade, preparado para abrir um e-mail ao administrador.
- Prévia visual de uma área de comentários para usuários cadastrados.
- Layout responsivo para celular e computador.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Sem frameworks ou dependências externas

## Executar localmente

1. Baixe ou clone este repositório.
2. Abra `index.html` em um navegador.

A página é estática; não é necessário instalar pacotes nem iniciar um servidor.

## Escopo e limitações atuais

- A lista de atividades foi montada a partir de informações iniciais sobre a praça e precisa ser validada com as pessoas responsáveis.
- Os horários de futsal e pintura são propostas de organização, não horários oficialmente confirmados.
- A referência a Juliana Alencar como responsável pela pintura também precisa de confirmação antes de divulgação oficial.
- O formulário usa `mailto:`: abre o aplicativo de e-mail da pessoa, não envia automaticamente e não armazena respostas.
- Cadastro, autenticação e publicação de comentários ainda não estão integrados. A área de comentários é apenas uma prévia visual.

Essas limitações são mantidas explícitas para não apresentar informações propostas como se fossem confirmações da comunidade.

## Próximas etapas

1. Validar atividades, responsáveis e horários com a comunidade.
2. Revisar o conteúdo e as imagens com as pessoas responsáveis.
3. Se o projeto avançar, implementar envio e armazenamento de propostas com proteção de dados.
4. Integrar autenticação, moderação e comentários com controles de segurança.
5. Fazer testes de acessibilidade e usabilidade com moradores.
